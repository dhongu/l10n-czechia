1. As an administrator, open **Contacts → Configuration → Localization → Cities** and search
   for a postal code: the Czech localities of that postal code are listed with their region.

   ![Cities list filtered on the postal code 101 00: the localities Michle, Praha 10-Michle, Praha 10-Vinohrady, all of the state Hlavní město Praha (CZ)](static/description/en/01_lista_localitati_cap.png)

2. Open a Czech contact and type the postal code in the address: the city and the region are
   filled in.

   ![Contact in Czechia: the postal code 252 63 fills in the city Roztoky and the state Středočeský kraj (CZ)](static/description/en/02_partener_cap_unic.png)

3. When the postal code is shared by several localities, only the region is filled in; choose the
   city from the list (type the postal code or the name in the city field).

   ![Contact in Czechia: the postal code 101 00 fills in the state Hlavní město Praha (CZ); the city field lists the localities of 101 00](static/description/en/03_partener_cap_comun.png)

4. To complete existing or imported contacts, select them in the list and run
   *Actions → Czechia: set city from ZIP*.

   ![Contacts list with Czech contacts selected and the Actions menu open on Czechia: set city from ZIP](static/description/en/04_actiune_contacte_existente.png)

   ![Contact Customer Michle after the action: ZIP 101 00, city Michle (101 00) and state Hlavní město Praha (CZ)](static/description/en/05_contact_dupa_actiune.png)
